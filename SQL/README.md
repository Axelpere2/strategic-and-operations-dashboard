# SQL Analysis

This folder contains SQL queries used to analyze SLA performance, incident trends, support team performance, breach reasons, and operational improvement opportunities.

## Main File

- `sla_breach_analysis.sql`

## Business Questions Answered

1. What is the overall SLA breach rate?
2. Which support teams have the highest SLA breach rate?
3. Which priorities create the highest SLA risk?
4. What are the main reasons for SLA breaches?
5. Which services and categories are most affected?
6. Do escalated tickets show higher SLA risk?
7. Which breached tickets require management attention?
8. Which recurring issues should be reviewed through Problem Management?
